# タスク管理アプリ（自分用）

Mac と iPhone で使える、完全無料のタスク管理 Web アプリです。

| 部品 | 中身 | 費用 |
|---|---|---|
| 画面（`docs/`） | HTML / CSS / JavaScript。iPhone ではホーム画面に追加してアプリとして使う | 無料（GitHub Pages で公開） |
| 同期サーバー（`gas/`） | Google Apps Script。データは自分の Google スプレッドシートに保存 | 無料 |

## 開発ロードマップ

- [x] フェーズ1：タスク / Todo（期限・優先度・プロジェクト・タグ・繰り返し・同期）
- [x] フェーズ2：Google カレンダー連携（期限付きタスクを「タスク」カレンダーに登録・通知、予定をアプリに表示）
- [x] フェーズ3：Gmail 連携（要返信メールを15分ごとに自動でタスク化、返信で自動完了）

## はじめて使う方へ

1. https://aoi052333.github.io/task-app/ を開きます。
2. 最初に表示される「**初回設定の案内**」に沿って進めると、約15分で同期の設定が完了します（無料）。
   - 同期用のプログラム（Google Apps Script）は**あなたの Google アカウントの中**に作られ、タスクやメールのデータが他の人に見られることはありません。
   - 案内は、あとから「設定」画面の「設定の案内を開く」でいつでも開けます。
3. iPhone では、Safari で同じページを開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます。

## セットアップ手順

### 1. 同期サーバー（Google Apps Script）を作る

1. ブラウザで https://script.google.com を開き、「新しいプロジェクト」を作成する
2. 左上のプロジェクト名を「タスク管理アプリ」に変更する
3. `コード.gs` の中身をすべて消し、このフォルダの `gas/Code.gs` の内容を貼り付けて保存（⌘S）
4. 上部の関数選択で `setup` を選び、「▶ 実行」を押す
   - 「承認が必要です」と出たら、自分のアカウントを選んで許可する
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」を押す（自分で作ったスクリプトなので問題ありません）
5. 下の「実行ログ」に表示される **トークン** を控える
6. 右上の「デプロイ」→「新しいデプロイ」→ 歯車アイコンから「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 「デプロイ」を押し、表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を控える

> 「全員」にしても、トークンを知らない人はデータを読み書きできません。トークンは他人に教えないでください。

> `Code.gs` を書き換えたときは「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」で反映します（URL は変わりません）。

### 2. 画面を公開する（GitHub Pages）

1. https://github.com でアカウントを作る（無料）
2. 新しいリポジトリを作る（例：`task-app`、Public）
3. このフォルダをリポジトリにアップロードする
4. リポジトリの Settings → Pages → Branch を `main` / `/docs` にして Save
5. 数分後、`https://<ユーザー名>.github.io/task-app/` で開けるようになる

> 公開されるのは画面のプログラムだけです。タスクのデータは自分の Google スプレッドシートにだけ保存されます。

### 3. アプリに同期設定を入れる

1. Mac のブラウザで公開した URL を開く
2. 左下の「設定」で、手順1で控えた **URL** と **トークン** を入力し、「保存して同期」を押す
3. iPhone の Safari でも同じ URL を開き、同じように設定する
4. iPhone では、共有ボタン →「ホーム画面に追加」でアプリのように使える

## 使い方

上の入力欄に書いて Enter を押すと、タスクが追加されます。

| 書き方 | 意味 |
|---|---|
| `今日` `明日` `明後日` | 期限日 |
| `金`（曜日） / `12/25` | 次のその曜日 / その日付 |
| `15:00` | 時刻 |
| `!高` `!中` `!低` | 優先度 |
| `#仕事` | プロジェクト |
| `@電話` | タグ |

例：`見積書を送る 金 10:00 !高 #仕事 @メール`

- 左の丸をクリック → 完了（繰り返しタスクは次回分が自動で作られます）
- タスクの本文をクリック → 詳細の編集・削除

## ローカルで動かす（開発用）

```bash
python3 -m http.server 8765 --directory docs
```

ブラウザで http://localhost:8765 を開きます。設定に URL を入れなければ、データは端末内だけに保存されます。
